# Deep Shift — Agent handoff

1. Create a **new empty GitHub repository** for the original game (e.g. `deep-shift`).
2. Add `DEEP_SHIFT_GAME_SPEC.md` to the repository as `docs/SPEC.md`.
3. Add `CLAUDE.md` to the repository root and `CLAUDE_CLOUD_KICKOFF.md` to the repository root.
4. At https://claude.ai/code connect the repository and paste the contents of `CLAUDE_CLOUD_KICKOFF.md` under **Prompt to Claude**.
5. Review the agent's PR, tests and GitHub Actions Mac build. Test the compiled Mac application locally before marking GUI functionality complete.
6. Continue with one focused phase per cloud session.

The files document *provisional* design defaults. They are not a guarantee that features have already been built or physically tested.
